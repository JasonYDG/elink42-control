# ELINK42 Web 0.7.8

[打开在线控制台](https://jasonydg.github.io/elink42-control/?v=0.7.8)

内置图库现有 106 张壁纸，统一显示主题名称，移除 AAA、BBB 两张总览缩略图。日历壁纸分为 12 张月份图、24 张独立节气图、20 张节日图和 6 张原有主题插画，不再把月份与两个节气合并命名。

首页不加载照片，也不下载内置固件包。打开“图片”后按可见区域加载小缩略图，滚动时继续加载；点击一张图才读取它的原图，确认后保存到设备空位置。日历图可在图片日历中选择。网页不会自动覆盖设备已有图片。

[图片库与使用说明](images/README.md) · [新增图片生成记录](images/generation-briefs-calendar.json)

原系列和 SDK 共用这个控制台。连接后按身份显示相应的设备信息、日历、图库和升级入口。SDK 8 的经典月历在公历年份旁显示生肖，于春节换年。可选经典月历、图片日历、月历全览、今日侧栏、全屏极简和单日极简六种样式。图片日历、今日侧栏和全屏极简用红色加粗液晶数字显示当日。SDK 9 的单日极简采用红色等高月日，底栏显示完整设备名、下个节日和电压。SDK 10 更新月历全览，公历日期放大，农历与节日改用 10 像素字形。SDK 6、7、8、9、10 的预览分别使用对应固件的 C 视图，未读取的设备照片在预览中留白。

SDK 12 将经典月历的星期、日期和农历按列居中，节气和倒计时共用一条中轴。SDK 使用板级蓝牙地址，以三色 3C 或四色 4C 加 MAC 末四位生成广播名。SDK 10 和 11 共用原预览，SDK 12 使用定稿布局。

## 升级路线

- 旧系列 v5 及 v3–14 通过对应屏型的 v31 过渡包升至 v32，再载入 v33。每段重连核对版本，原系列 OTA 会使用内部图库暂存，升级前需要备份。
- SDK 2 及以后使用对应屏型的 .e42ota。SDK v5 收到包之后仍会执行它自身的分区检查，有 USR1 重叠的旧布局会停止。
- v33 继续使用原控制入口。SDK 设备进入「更多 → OTA 升级」，点击「刷入内置 SDK 12」。页面按屏型选包并核对运行镜像 CRC。SDK 2–10 升级后，请在屏幕显示新名称时重新选择该名称，网页会自动读取设备地址并核对升级结果。曾经同名的屏幕请逐台供电升级。

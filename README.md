# ELINK42 Web 0.6.22

[打开在线控制台](https://jasonydg.github.io/elink42-control/?v=0.6.22)

内置图库现有 106 张壁纸，统一显示主题名称，移除 AAA、BBB 两张总览缩略图。日历壁纸分为 12 张月份图、24 张独立节气图、20 张节日图和 6 张原有主题插画，不再把月份与两个节气合并命名。

打开“图片”中的内置图库，点击缩略图即可载入预览；确认后保存到设备空位置。日历图可在图片日历中选择。网页不会自动覆盖设备已有图片。

[图片库与使用说明](images/README.md) · [新增图片生成记录](images/generation-briefs-calendar.json)

设备升级在控制台内连接设备后操作，网页按实际屏型载入内置的签名 v33。保留原有兼容检查、备份确认和失败停止流程。升级会清空设备图库，请先备份。

当前网页和源码目录不提供独立固件下载入口。静态网页中的内置升级资源仍可由浏览器读取，历史 Git 版本也不因当前文件下架而消失；这不构成固件访问控制。

本次只更新壁纸、网页版本及固件下载入口。内置固件、蓝牙协议和显示驱动保持原字节。软件预览与自动检查不代表真实屏幕观感已验收。

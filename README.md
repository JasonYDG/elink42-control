# ELINK42 Web 0.6.15 / 离线换图 v24

[在线控制台](https://jasonydg.github.io/elink42-control/) · [原图与12个月节气壁纸](https://github.com/JasonYDG/elink42-control/tree/main/images)

网页现在有四个入口：日历、图片、设备图片、更多。图片页直接内置59张小缩略图，点选载入预览，保存才发送。手机可触摸滚动，裁切和旋转收在高级设置。界面支持 English、简体和繁体；屏幕继续使用现有简体字库、中国/新加坡/台湾日历。

## 换一张图

先连接设备，再点击“一键换图”。设备是图片日历时更换左图，右侧日期保留；全屏图片则更换全屏图。新图顺延写入下一个空位置，到末尾再找前面的空位。全部存满就提示手动删除，不会覆盖。

也可以在“图片”页选择缩略图或手机文件，预览后点击“保存并显示图片”或“保存并启用图片日历”。“仅保存”用于先存素材；设备已存图片在“设备图片”中管理。保存记录先核对长度、格式和CRC，再提交显示；显示失败时明确保留保存位置，不自动重写。

日历原图应选256×300比例，新保存的专用日历图填满左侧。旧图如果已经保存了白边，需要从原图重新保存。全屏原图用于日历且选择“完整保留”时会按比例留白。

## 关闭网页后自动换图

离线日、周、月轮播需要v24。启用图片日历或换图时，同一存储源有两张以上有效图片，默认每天凌晨0点轮换；可以选择每周一0点、每月1日0点或关闭。使用设备校准后的本地时间，关闭网页、断开蓝牙后仍由设备执行。

当前存储源的全部有效图片参与轮播；旧图库没有“全屏/日历”用途标签，请自行保留适合当前用途的素材。日历右侧每天更新，左图按所选频率轮换。四色仍为全屏物理刷新；原有每五天清屏维护保留，未到换图日时会重新绘制当前图片。

重启仍按原约定显示设备名、完整MAC和版本，自动显示暂停，需手动重新启用。图片和频率的保存不会取消这个开机规则。

## OTA升级

一个ZIP，备份图库、确认一次，最多两次写入。稳定的v21直升v24，只需一次。

| 当前版本 | 写入路线 |
|---|---|
| v5、v11–v14 | 对应旧基线静默v23 → v24 |
| v16–v17 | 对应修复基线静默v23 → v24 |
| 已发布v18 | 精确原配v19 → v24 |
| 已发布v20 | 精确原配v21 → v24 |
| v19、v21、v23 | v24，一次 |
| v15 | 拒绝：旧接收器锁定v16，不能在两次写入内完成 |
| v24或更高 | 不升级、不回退 |

签名、屏型、配对、每次重启版本和同一设备均核验。失败停止，不自动重发。OTA会清空图库；页面停留OTA时不会触发三分钟闲置断连，传输与重启确认期间也有保护。电压保持两位小数。

## 验证边界

本轮没有连接或刷写屏幕。离线指令、日期边界、字体、故障注入、虚拟OTA与隔离浏览器检查不能代替真实电池、实屏效果及长期离线运行验收。相对v21，底层蓝牙/射频、面板驱动、波形、超时、复位、身份、校准、密钥和存储边界逐字节保持。仍基于稳定的第三方基础，并非完整SDK重建。

本地整合包解压后运行Start.cmd。公开源码可用Python3运行 `python tools/build_site.py`，Node.js运行 `node --test tests/*.cjs`。原图保持不变，缩略图约430KiB，完整预览图按选择加载。

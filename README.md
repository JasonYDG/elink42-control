# ELINK42 Web 0.7.0

[打开在线控制台](https://jasonydg.github.io/elink42-control/?v=0.7.0)

内置图库现有 106 张壁纸，统一显示主题名称，移除 AAA、BBB 两张总览缩略图。日历壁纸分为 12 张月份图、24 张独立节气图、20 张节日图和 6 张原有主题插画，不再把月份与两个节气合并命名。

首页不加载照片，也不下载内置固件包。打开“图片”后按可见区域加载小缩略图，滚动时继续加载；点击一张图才读取它的原图，确认后保存到设备空位置。日历图可在图片日历中选择。网页不会自动覆盖设备已有图片。

[图片库与使用说明](images/README.md) · [新增图片生成记录](images/generation-briefs-calendar.json)

原系列和 SDK 共用这个控制台。连接后按身份显示相应的设备信息、日历、图库和升级入口。SDK 6 的日历预览与设备共用 C 视图，未读取的设备照片在预览中留白。

## 升级路线

- 旧系列 v5 及 v3–14 通过对应屏型的 v31 过渡包升至 v32，再载入 v33。每段重连核对版本，原系列 OTA 会使用内部图库暂存，升级前需要备份。
- SDK 2 及以后使用对应屏型的 .e42ota。SDK v5 收到包之后仍会执行它自身的分区检查，有 USR1 重叠的旧布局会停止。
- v33 到 SDK 6 需要专用跨系列过渡接收器；当前包只包含两个系列各自已经验证的更新。

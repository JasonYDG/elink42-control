# ELINK42 Web 0.6.19 / 设备固件 v32

日常刷屏低压门槛从 2.90 V 降到 2.70 V；低于 2.80 V 提示低电量。低于门槛的新刷新会明确报错，软件不会因此主动断开蓝牙。电池带载压降和整机最低工作电压仍须实机验证。

连接详情新增设备实际 MAC、电压和手动采样；支持返回固件初始页，停止日历与轮播并保留图片。初始页放大设备名，使用屏型支持的三色或四色。v32 应用区以外每个字节与 v30 一致；未改蓝牙底层、正常波形、复位、校准、身份和存储边界。

## 升级路线

一个 ZIP、确认一次、内部最多两次写入，每次重启核对同一设备与版本。失败停止，不自动重发。

| 当前版本 | OTA 路线 |
|---|---|
| v3–14（含 v10/v12 诊断版）、v16–17、v19/v21/v24/v28 | 匹配当前基线的 v31 → v32 |
| v29 | 其精确配对的 v30 → v32 |
| v30、v31 | v32，一次 |
| v1/v2、锁定旧镜像的 v15/v18/v20/v23/v27 | 使用对应屏型 HEX |
| v32 或更高 | 整合包不升级、不回退 |

v3/v4 启动记录超限时在擦除前拒绝，改用 HEX，不绕过检查。OTA 会清空设备图库，请先备份；停留 OTA 页面、传输、校验及等待重启期间均暂停三分钟空闲断连。v32 及以后可读电压，网页 OTA 单独要求至少 2.90 V；更旧固件没有本次电压协议，请使用状态良好的新电池。

## 有线安装

对应屏型 HEX 可直接安装 v32，完整覆盖应用区 `0x00404000–0x0043E3C3`，238,532 字节；保留现有引导、MAC、校准和身份，不可全片擦除。它不包含空白芯片引导程序。没有连接或刷写任何设备，实物显示、供电与长期蓝牙运行待验收。

## 日常使用

网页保留日历、图片、设备图片、更多四个入口，58 张内置缩略图及 12 个月节气壁纸。界面支持 English、简体和繁体，设备继续按现有字库能力显示中国、台湾、新加坡日历。新保存的 256×300 日历壁纸填满左侧，右侧日期由设备更新。

“一键换图”按当前模式更换左侧或全屏图片，顺延使用空位置，满了提示手动删除。多图可离线按每天、每周或每月凌晨 0 点更换。保留 v24 的日期、字体和换图逻辑，以及 Web 0.6.16 避免重复刷新、等待就绪后提交轮播设置的修复。

## 验证范围

执行真实 Thumb 代码与故障化 MMIO，覆盖正常路径、外设不就绪、运行中停钟、超时后的清理及下一次状态查询。旧版同条件能复现卡住，新版可返回。完整虚拟 OTA 执行原生签名、SHA、保护区、精确目标配对和启动记录读回，不能代替实物 OTA 或无线链路长期验收。

ROM 内部不返回、设备供电和射频环境不在这些离线测试的保证内。系统复位命令的其他等待、真实 RTC 重入的可达性，未在本次 SPI/UART/Flash 范围内改写。

公开控制台源码可用 Python 运行 `python tools/build_site.py`，Node.js 运行 `node --test tests/*.cjs`。本地整合包解压后运行 `Start.cmd`。私有签名密钥、SDK、ELF 和固件分析工作区不在公开包中。

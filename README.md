# ELINK42 Web 0.6.8

[打开 HTTPS 控制台](https://jasonydg.github.io/elink42-control/)

停留在 OTA 页面时暂停三分钟空闲断连；离开后重新计算完整三分钟。连接屏幕后继续停留在 OTA 页。升级上传、签名与哈希校验、提交和等待重启核对版本期间，原有操作锁继续保护连接；失败会保留错误处理，不自动重刷。

网页界面提供 English、简体中文和繁體中文，记住本浏览器的选择；不转换用户输入或更改设备屏幕字库。日历地区为中国、新加坡、台湾，协议 ID 保持 0、2、3；v14 屏幕仍使用简体中文。旧地区与英文屏幕偏好迁移到支持的设置，其他工作区内容保留。

网页继续内嵌既有三色 SSD1619／四色 JD79668 的 v11 签名包；本次没有替换固件包或提升 v14 稳定性状态。低于内置版本时可前往 OTA；读取版本、验签、哈希、保护区、目标屏型、图库清空确认及重启版本核对全部保留。更新会清空图库，先备份；不会自动开始升级。

使用支持 Web Bluetooth 的 Chrome / Edge。首次更换网页来源需重新授权蓝牙；本地与 GitHub 网页分别保存工作区，可导出后导入。关闭网页后，本页定时任务停止；四色原驱动没有局刷接口。台湾假期为政府行政机关办公日历，中国覆盖 2026，另两项覆盖 2026–2027。

公开仓库只有控制端与已签名 OTA 资源，不含私钥、固件源码、SDK 或线刷文件。GitHub Pages 禁用需要私钥的天气代理，仍可导入天气缓存；点击一言时访问 uapis.cn。

## 验证与部署

使用 Python 3 和 Node.js，无需安装依赖：

```sh
python tools/build_site.py
node --test tests/*.cjs
python -m http.server 18777 --directory build
```

预览地址为 `http://127.0.0.1:18777/elink42-control/`。`main` 保存源码，`gh-pages` 部署允许清单中的 15 个资源及资源校验清单；HTML 使用 Web 0.6.8 和实际发布文件的哈希刷新缓存。

OTA 正向 UI 测试通过 `OM6626_OTA_PACKAGE_ROOT` 指向私有签名包夹具；未提供时跳过这些用例，非法包检查始终执行，夹具不进入公开构建。本轮未连接或刷写设备，实机 OTA 和长期重连仍须验证。

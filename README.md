# ELINK42 Web 0.6.12 / 两阶段 OTA v19

[打开在线控制台](https://jasonydg.github.io/elink42-control/)；连接后点击“载入内置 v19 两阶段升级包”，备份图库并确认一次。网页使用一个 ZIP，按设备读回的屏型和版本自动选择路线，最多执行两次固件写入。

| 当前独立固件 | 自动执行的阶段 |
|---|---|
| v11–v14 | 旧基线静默 v18 → 确认启动与模式 0 → v19 |
| v16–v17 | 修复基线静默 v18 → 确认启动与模式 0 → v19 |
| v18 | 确认静默状态 → v19，仅一次写入 |
| v15 | 拒绝本包；旧接收器锁定原 v16，不能满足最多两次写入 |
| v19 或更高 | 不升级、不回退 |

每次重启重新连接同一设备并核对屏型、版本；中间接收器还必须读回模式 0，确认后才继续。任一阶段失败即停止，不自动重发。刷新网页后重新连接、读回版本，再确认是否继续。每次 OTA 都会清空图库，请先备份并保持供电。

升级准备暂时把设备时间设置为 1970-01-01 00:00、模式 0，不再调用旧屏幕初始化或休眠命令。静默 v18 保留电子纸原画面，仅用于接收最终版；最终 v19 每次启动都进入静态初始页，只显示设备名字、完整蓝牙 MAC 和固件版本。日历与校时需手动启用。升级前关闭其他控制台标签页。

v19 补齐面板初始化、刷新、休眠、供电、RST 和 ADC 的有界等待。冻结计时器或外设超时会返回错误并清理；ADC 失败不会伪装成 0 V。BLE BUSY 事件泵返回后重新核对 DWT 计时门，避免最后一次事件处理关闭计时门导致后续休眠永久等待。新增带回执的排队初始化，网页在 v19 使用它。

保留电压两位小数和节气当天的显示修正：全屏“今天是立冬”，分屏当天先显示今日节气，从次日显示后续倒计时。采样校准、正常复位脉冲、波形、射频、Bootloader、设备身份、密钥和 NVDS 存储边界保留；这不是全芯片重置。当前仍基于第三方参考固件，不是官方 SDK 完整重建。

OTA 页、传输、校验和重启确认期间暂停三分钟空闲断连，离开后重新计时。界面支持 English、简体和繁体；屏幕按现有简体字库显示，中国/新加坡/台湾 ID 为 0/2/3。仅支持本项目兼容独立 OTA 固件的 SSD1619 三色 model 2、JD79668 四色 model 5。

所有六个内部镜像分别验证项目签名、哈希、屏型、保护区和配对目标；外层 ZIP 包含 LICENSES.txt。私钥、源码、SDK 和线刷文件不进入公开站点。本轮未连接或刷写实体设备；离线故障复现证实了软件缺陷，尚不能判定 972B 当时具体停在哪个等待点。

双击 Start.cmd 启动本地控制台。Chrome / Edge 支持 Web Bluetooth。

## 验证与部署

使用 Python 3 和 Node.js：python tools/build_site.py，node --test tests/*.cjs。main 保存源码，gh-pages 仅部署 15 个允许资源和 site-manifest.json。

# ELINK42 Web 0.6.14 / 日历显示 v21

[在线控制台](https://jasonydg.github.io/elink42-control/) · [全屏图片 / 日历壁纸 / 12个月节气](images/)

图片日历日期改为更大的红色七段液晶字形，单字最大 38 × 56 像素，整数矩形绘制。全屏右下角使用 24 像素字高，显示“14天后小雪”；当天显示“今天是小雪”。网页预览同步。设备绘图需要升级 v21。

日历比例图片自动识别并重置缩放、旋转和偏移。保存至设备空槽后，图片日历选择“专用日历图片”，填满左侧 256 × 300。完整全屏图片模式会缩小并留白；旧槽中已经带白边的像素须重新保存原图。

原 Image 文件夹 47 张全部保留原字节；新增 12 张黑白红黄节气主题壁纸，覆盖 1–12 月。高分辨率原图由网页按屏型转换为设备像素，详见[图片库](images/README.md)。图片保存在 main，Pages 仍只发布 16 个控制台文件。

## 升级路线

一个 ZIP，备份图库并确认一次，最多两次实际写入：

| 当前版本 | 写入路线 |
|---|---|
| v5、v11–v14 | 旧基线静默 v20 → v21 |
| v16–v17 | 修复基线静默 v20 → v21 |
| 已发布 v18 | 原配 v19 → v21，保留精确目标校验 |
| v19、v20 | v21，仅一次 |
| v15 | 拒绝，旧接收器锁定 v16，无法满足最多两次写入 |
| v21 或更高 | 不升级、不回退 |

每次重启核对同一设备、屏型、版本；静默接收器必须读回模式 0。失败停止，不自动重发。OTA 会清空图库，请先备份并保持供电。最终重启只显示设备名、完整 MAC 和版本；日历手动启用。

## 保持通讯稳定

v21 相对 v19 仅改变已核验日历和 OTA 应用区域。蓝牙/射频、底层显示驱动、波形、超时保护、复位脉冲、身份、密钥、校准及存储边界逐字节保持。未增加任务、定时器或通讯协议，v19 的 DWT、SPI、BUSY、ADC 保护保留。v5 的暂停回执兼容、OTA 操作锁、失败停止和页面三分钟挂起保护保留。

本轮没有连接或刷写设备。离线原生指令、像素、栈、签名、保护区和虚拟 OTA 验证不能代替实机观感和长期稳定性测试。仍基于第三方参考基础，并非官方 SDK 完整重建。

网页支持 English、简体和繁体；设备按现有简体字库显示，中国/新加坡/台湾协议 ID 保持 0/2/3。电压两位小数。支持兼容独立 OTA 的 SSD1619 三色 model 2 和 JD79668 四色 model 5。

## 构建

Python 3：`python tools/build_site.py`；Node.js：`node --test tests/*.cjs`。main 保存网页源码和图片；gh-pages 仅部署 15 个允许资源和 site-manifest.json。私钥、原始 BIN/HEX、SDK 和固件源码不进入公开站点。

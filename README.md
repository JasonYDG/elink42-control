# ELINK42 Web 0.8.10

网站使用七项主菜单：日历、图片日历、提醒日历、课程日历、股票日历、图库、设置。天气页面和天气定时任务入口已移除，旧备份仍可导入；历史天气任务执行时会停止并提示，不会联网或发送到屏幕。预览固定显示实际400×300画面，修改先保存在网页，点击应用后才改变设备。

| 网页入口 | 实际执行方式 |
| --- | --- |
| 日历 / 图片日历 | 按固件能力启用设备日历；校时并应用后由设备按日期更新 |
| 提醒日历 | SDK18保存结构化事项与原尺寸字形，离线换日及到时更新；较旧固件可发送当前画面 |
| 课程日历 | SDK16及以上保存课程、考试及字形，支持全天和周一至周五；表格与Excel导入共用同一数据 |
| 股票日历 | 网页读取A股指数和个股行情，按交易时段刷新；自动同步需保持网页开启和目标蓝牙连接 |
| 图库 | 读取对应内部/外置存储，普通图片与原生课程/提醒记录区分显示 |
| 设置 | 显示实测设备信息、按设备系列与屏型匹配OTA，SDK内置包为18 |

配套SDK18候选已通过软件与模拟验收，实际屏幕、蓝牙空口、休眠唤醒及长期离线运行尚待实机验收。股票画面不属于设备自行联网生成行情。

Web 0.8.9配套SDK18：提醒采用课表同款雅黑，按12/20/24/36px实际字号生成字形，保留原布局和原色；六字标题在24px完整单行，当天36px按词组换行。ELREM02记录存放字形和换行位置，离线时无需电脑提供字体；旧ELREM01保持兼容。新版自动提醒需SDK18，旧固件仍可发送当前画面。

Web 0.8.8 配套 SDK 17，将审核通过的提醒日历接入原生数据和固件绘图。选择日历、图片日历、全天/周课表或提醒日历，选“设备离线自动更新”，确认预览后应用到屏幕。同步完成、设备已校时且持续供电时，可关闭网页并断开蓝牙；设备按时钟换日、换月、换周及切换当天到时事项。重启仍按原有行为返回初始页，需要重新校时、恢复方案；不承诺断电自动恢复。

提醒主标题倒数时24px黑字，当天36px红色粗体，“今天”20px黑字。所有未完成提醒保存在设备记录中，屏幕展示主事项与两条其他提醒；已完成事项不上传。最多64条未完成事项、每个标题100字符，并受30,000字节内容与字形总容量限制；超限或不支持的字符会拒绝同步。可选择单项，单项选择、标题、待办、课表、考试和背景均包含在完整方案JSON中。导入只修改网页，应用后才改变设备。

网页预览与固件共用C绘图；SDK 17同步还核对完整记录CRC32、格式、位置和启用状态。先写空槽、验证并启用新记录，再清理已识别的旧应用记录；照片不会被自动覆盖。SDK 15/16仍可用静态提醒，离线提醒需升级SDK 17。设置中的网页定时推送仍依赖页面开启；股票的新行情仍需联网来源，不能离线产生报价。

验证：`source/tests/verify_school_native.py`覆盖两种屏型，真实网页打包/BLE客户端连接编译后的C内核。关闭页面、断开模拟BLE后，验证日历换月、照片日历换日、日/周课表换周以及6个提醒时间点；离线绘制不写Flash。网页编辑、单项、完成、导入导出及恢复后的8组画面逐字节一致；旧格式与两张原图比对，新格式检查实际字形尺寸和“完成 / 数学练习”语义换行。此为软件验收，真实屏幕显示、RTC休眠唤醒与长期离线运行尚待实机验收。

内置图库现有 106 张壁纸，统一显示主题名称，移除 AAA、BBB 两张总览缩略图。日历壁纸分为 12 张月份图、24 张独立节气图、20 张节日图和 6 张原有主题插画，不再把月份与两个节气合并命名。

首页不加载照片，也不下载内置固件包。打开“图片”后按可见区域加载小缩略图，滚动时继续加载；点击一张图才读取它的原图，确认后保存到设备空位置。日历图可在图片日历中选择。网页不会自动覆盖设备已有图片。

屏幕方案统一提供日历、图片日历、全天课表和周一至周五课表。400×300预览使用设备同一份C绘图代码；点击日期、课表或页脚进入对应设置。课程在本页表格录入或Excel导入，保存后核对预览，再点击“应用并自动更新”。课程黑色、考试红色；考试周列合并，自习不显示。课程最多每天12节，考试最多64场；超过一页用页码切换，原始周末数据保留。

Web 0.8.7 移除股票页底部的单位说明和重复行情时间，保留设备名、电压，采用与日历相同的12px小字、283像素页脚基线和电池标识。顶部日期与更新时间统一12px，A股自选标题收为20px，与缩小的柱形标识对齐，减少标题对行情的压迫。行情表、提醒时段及硬件读取逻辑保持原行为。

Web 0.8.6 按股票参考图调整标题、日期、黑底表头、分隔行和涨幅强调。股票文字复用日历的 Fusion Pixel 10/12px 点阵字库，以整数倍绘制，直接生成面板原色，避免浏览器字体抗锯齿量化后缺笔和杂色。正涨幅为红字，四色屏加黄底；跌幅保持黑色，三色屏不使用黄底。保留3–5条行情、设备名、电压和完整行情时间。连接后顶部常驻显示主控、屏型、设备固件版本和实测电压，设置页详情自动展开。内置固件未改动；SDK 15 的实机重连问题仍待排查。

Web 0.8.5 修复连接时仅依赖首次配置通知的问题：支持读取的控制接口在通知未到达时直接读回并校验配置；通知型旧设备继续等待通知。读取失败或超时会清理连接，迟到的旧读取不会断开新连接。请先在旧标签页断开同一屏幕，再从当前页面连接，避免多页同时控制。设备固件保持 SDK 16；现场连接恢复仍需核对具体设备。

Web 0.8.4 对股票画面执行黑白二值编码，以正负号表达涨跌，避免抗锯齿灰度被四色量化为杂色。将股票画面改为顶部日期与全宽行情表，显示真实最新价、涨跌额、涨跌幅和行情时间，保留设备与电量。自动获取和自动推送仅在北京时间的竞价交易时段进行，午休/夜间/周末/已核验的2026休市日暂停。休市可手动获取最近快照；未知年份暂停自动更新，待核验交易日历。时段依据上交所交易规则与2026休市公告；设备固件仍保持 SDK 16。

Web 0.8.3 修复 Edge 跟踪防护拦截行情请求导致的 Failed to fetch。本地网页通过同源只读接口取数，保留浏览器保护设置；接口仅接受1–5个行情代码，限制上游地址、超时和响应大小，不包含硬件操作。

本地运行：在网页包目录执行 `python tools/serve_local.py --port 8289`，打开 `http://127.0.0.1:8289/`。在本项目根目录保留原地址时，使用 `python source/github-web/tools/serve_local.py --directory . --port 8289`。普通 `python -m http.server` 只提供静态预览。保留已运行的 8289 静态服务时，可独立运行 `python tools/serve_local.py --port 8290 --quotes-only --allow-origin http://127.0.0.1:8289 --allow-origin http://localhost:8289`；网页会自动发现本机行情接口，无需移动浏览器本地数据。线上静态站点仍使用直连，可能受浏览器或网络限制。

Web 0.8.2 恢复五个默认日历方案，统一七项主导航，采用配置与固定预览并排的布局。提醒日历复用待办；A股日历通过 腾讯财经 HTTPS 行情接口获取，显示行情时间，支持网页定时获取及指定连接设备同步。行情服务故障保留旧数据，第三方可用性与实屏定时同步需分别验收。固件仍为 SDK 16，本版不生成或改写固件。

Web 0.8.1修复SDK 12遗留OTA错误阻断用户再次开始升级，提供只读升级状态、原始回执、接收字节、电压和失败阶段。首个Flash错误原因仍需实机诊断；不自动重传。配套SDK 16改善课表Flash读取，并提供运行状态与图片读取。SDK 15自动课表入口已被阻止，仍可选择“保持当前画面”发送；升级后使用新版本自动课表。旧数据格式和设置保持兼容，不覆盖已有图片。仅通过软件验证，真实蓝牙、实屏及长期运行待验收。

“导出方案”保存完整工作区、课程、考试、布局、地区及已备份背景；“导入方案”先备份旧方案，再恢复网页，确认后手动应用。背景需先从网页保存或点击“读取所选图片到预览”，只选设备槽号不能代替背景备份。SDK OTA开始前保存方案到本机，不弹出文件下载；文件备份请点“导出方案”。重连后点击恢复，无需再次录入。JSON保存在本机浏览器/下载文件，不上传服务；更换浏览器或清理数据前请导出。

## 升级路线

- 旧系列 v5 及 v3–14 通过对应屏型的 v31 过渡包升至 v32，再载入 v33。每段重连核对版本，原系列 OTA 会使用内部图库暂存，升级前需要备份。
- 已经停在 v15、v18、v20、v23 或 v27 的设备，点击「载入原配无线升级包」分别升到 v16、v19、v21、v24 或 v28。原 Portal 按设备屏型选择已有签名包；读回成功后，再次载入内置包继续。操作记录中的「重启读回」列出设备报告的屏型和版本。
- SDK 2 及以后使用对应屏型的 .e42ota。SDK v5 收到包之后仍会执行它自身的分区检查，有 USR1 重叠的旧布局会停止。
- v33 继续使用原控制入口。SDK 设备进入「设置 → OTA 升级」，点击「刷入内置 SDK 18」。页面按屏型选包并核对运行镜像 CRC。SDK 2–10 升级后，请在屏幕显示新名称时重新选择该名称，网页会自动读取设备地址并核对升级结果。曾经同名的屏幕请逐台供电升级。

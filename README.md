# ELINK42 Web 0.6.11 / 整合 OTA v17

[打开在线控制台](https://jasonydg.github.io/elink42-control/)；连接后点击“载入内置 v17 整合升级包”，备份图库并确认一次，即可按设备当前版本完成升级。无需分别选择 v15、v16；原签名 v15、v16 与新 v17 已合在同一个 ZIP。网页会自动按读回屏型选择 SSD1619 三色或 JD79668 四色。

| 当前独立固件 | 自动执行的阶段 |
|---|---|
| 低于 v15 | v15 → 确认启动 → v16 → 确认启动 → v17 |
| v15 | v16 → 确认启动 → v17 |
| v16 | v17 |
| v17 或更高 | 不升级、不回退 |

每一步重新连接同一设备并核对屏型和版本，确认后才继续；中间不启用日历或时间同步。任一阶段失败即停止，不自动重发。网页刷新后需重新连接并读取版本，再由用户确认是否继续。每次 OTA 都会清空图库，请先备份，保持供电和页面开启。

只适用于已经运行本项目独立 OTA 固件的 model 2/5。第三方原版或缺少兼容接收程序的旧 v1 不能靠整合包绕过设备检查。不能通过设备名称末四位推断屏型。

v17 将设备电压四舍五入显示为两位小数，例如 3016 mV 显示 3.02 V；采样与低电压阈值不变。全屏日历在节气当天显示“今天是立冬”；分屏当天优先显示“今天是 / 立冬”，从次日起恢复后续倒计时。中国、台湾的当天节气优先逻辑与网页预览同步；其他日期的各地区假期规则保留。

停留 OTA 页、传输、校验及重启核对期间暂停三分钟空闲断连，离开后重新计算完整 180 秒。界面支持 English、简体和繁体；设备屏幕按固件字库使用简体。中国/新加坡/台湾协议 ID 为 0/2/3。

所有阶段分别验证项目签名、固件哈希、屏型和保护区；原 v15 仅允许固定配套 v16，整合包保留这一配对。整合 ZIP 内含 LICENSES.txt。私钥、固件源码、SDK 和线刷文件不进入公开站点。本轮只做软件验证和发布，未连接或刷写实体设备；实机显示、BLE、掉电恢复和长期稳定性仍待验收。

## 验证与部署

使用 Python 3 和 Node.js，无需安装依赖：

```sh
python tools/build_site.py
node --test tests/*.cjs
```

main 保存源码，gh-pages 仅部署 15 个允许资源和 site-manifest.json。整合升级与签名测试直接使用公开的 firmware.js；历史独立包 UI 测试可通过 OM6626_OTA_PACKAGE_ROOT、OM6626_REPAIR_ROOT、OM6626_TRANSITION_BUILD 指向私有测试夹具，夹具不进入公开构建。

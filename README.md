# ELINK 4.2 网页控制端

[打开 HTTPS 控制台](https://jasonydg.github.io/elink42-control/)

此仓库只发布 4.2 寸 OM6626 屏幕的网页控制端。与 2.13 寸项目分别维护，支持 SSD1619 三色和 JD79668 四色。

不包含固件镜像、OTA 包、固件源码、SDK 或固件下载。OTA 页面只校验用户从本机选择的升级包，不提供下载或自动获取固件。

使用支持 Web Bluetooth 的 Chrome / Edge，点击“连接屏幕”自行选择设备。首次更换网页来源时，需要重新授权蓝牙；本地网页与 GitHub 网页的数据分别保存，切换前导出工作区，再导入新网页。

提供设备日历/时钟控制、图片、待办、模板、图库、轮播、课表、LED 和页面定时任务。功能取决于设备已有固件能力；关闭网页后，本页定时任务停止。四色原驱动没有局刷接口。

GitHub Pages 无法提供私钥天气代理，在线版禁用实时天气请求，仍可使用导入的天气缓存和模板；一言在点击时访问 uapis.cn 公共接口。实时天气使用另行保存在本机的控制端。

## 验证与部署

只需 Python 3 和 Node.js，无须安装依赖：

```sh
python tools/build_site.py
node --test tests/*.cjs
python -m http.server 18777 --directory build
```

预览地址为 `http://127.0.0.1:18777/elink42-control/`。`main` 保存网页源码与测试，`gh-pages` 仅部署 11 个控制端资源及资源校验清单。

OTA 正向验签 UI 测试需要使用者通过 `OM6626_OTA_PACKAGE_ROOT` 指向本机私有测试夹具；未提供时明确跳过，夹具不会被复制进构建输出。非法包拒绝测试始终运行。

本次发布未连接或刷写设备，实机行为仍需验收。网页会在开始 OTA 前提示备份图库并确认清空。

# ELINK42 v30 / Web 0.6.18

本次包包含两种屏型的签名 OTA 与完整应用 HEX。未连接、刷写任何设备；实物显示、供电和长期蓝牙稳定性待实机验收。

- OTA：v3–14、v16–17、v19、v21、v24、v28 经匹配的 v29 到 v30，最多两次写入。v29 继续一次。每次启动版本必须读回一致，失败停止，不自动重发。
- v1/v2 的启动记录检查不兼容，请使用对应 HEX。v3/v4 仍要求启动记录可核验；若旧记录长度超限则在擦除前拒绝，不绕过检查，请使用 HEX。
- v15、v18、v20、v23、v27 接收器锁定原配旧镜像，无法在两次写入内到 v30，本网页不发送升级命令；请用对应屏型 HEX。旧包与旧固定镜像保留。
- OTA 沿用暂存区 0x40000–0x7A3C3，会清空设备图库，先备份。最终 v30 安装并重启后才具备本次全部等待保护；过渡固件保留对应旧基线。
- HEX 仅覆盖 0x00404000–0x0043E3C3，共 238,532 字节；保留现有引导、MAC、校准与身份区。不可全片擦除；不是空白芯片的引导程序。三色用 SSD1619，四色用 JD79668，不能交叉刷写。
- 修复无配置首次开机绕过启动策略，以及首次绘图被延迟到蓝牙连接的问题；启动时显示放大的设备名、完整 MAC 与固件版本；日历仍需手动启用。午夜换图和单次图片日历刷新逻辑保留。

沿用 v28 已发布的 SPI0/1 复位等待保护、UART 初始化/发送等待保护、Flash 就绪与延时等待保护，以及 Flash 校验失败后无限重试；计时器停走也能退出。本次检测到的 Flash 错误会中止接收和后续写入，不提交有效图片或启动记录。UART 由原调用者恢复原中断状态。原蓝牙代码、面板波形与正常外设写入顺序保留。

ROM 内部调用及真实硬件的非返回行为不在本次离线验证保证内。复位系统命令的其他等待与 RTC 重入候选风险未在本次改写。

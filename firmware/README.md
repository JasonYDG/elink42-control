# ELINK42 v32 / Web 0.6.19

本次包包含两种屏型的签名 OTA 与完整应用 HEX。没有连接或刷写设备；真实供电、显示与长期蓝牙稳定性仍待验收。

- 日常刷新：实测电压低于 2.80 V 提示低电量；2.70 V 及以上允许刷新，包括 2.90 V。低于 2.70 V 的新刷新命令明确拒绝并保留蓝牙查询。该门槛不改芯片 BOR、启动硬件或电池校准，也不是整机低压工作保证。
- 网页连接详情显示设备实际 MAC、电压（两位小数），支持手动重新采样。旧版缺少此读回协议时提示升级，不使用浏览器连接 ID 冒充 MAC。
- 返回固件初始页：停止日历与自动换图，通过现有流程刷新一次；已存图片保留。初始页放大设备名、MAC 与版本，三色为黑白红，四色增加黄色。
- OTA 写入保护单独处理：v32 及以后由网页先读电压，低于 2.90 V 或采样失败时在擦写前停止；旧版不支持读回，无法替它测量，请使用状态良好的新电池。正常读数不能排除带载压降。
- OTA：v3–14、v16–17、v19、v21、v24、v28 经匹配的 v31 到 v32；旧 v29 必须先收原配 v30 再到 v32；v30/v31 只需一次。一个 ZIP、确认一次，内部最多两次写入。每次重启核对同一设备和版本，失败停止，不重发。
- v1/v2 启动记录检查不兼容；v3/v4 若启动记录长度超限，也会在擦除前拒绝。v15/v18/v20/v23/v27 锁定原配旧镜像，无法在两次写入内完成，请用对应 HEX，不绕过检查。
- OTA 沿用暂存区 0x40000–0x7A3C3，会清空设备图库，请先备份。过渡接收器保留对应旧基线，其 C 绘图被抑制，但不保证所有旧原生初始化路径完全不驱动面板。
- HEX 完整覆盖应用区 0x00404000–0x0043E3C3，共 238,532 字节。保留现有引导、MAC、校准和身份，不可全片擦除；不包含空白芯片引导程序。三色 SSD1619 与四色 JD79668 不能交叉刷写。

v32 的应用区以外每个字节与已发布 v30 一致，包括蓝牙、原有 SPI/UART/Flash 等待保护、面板波形、复位与身份处理。不扩大已审查的应用区、RAM、栈或存储边界。本项目仍依赖既有第三方应用二进制，并非官方 SDK 全源码重建。
